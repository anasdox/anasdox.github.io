  <h2>a4m — AI-native engineering CLI</h2>
  <p class="meta">Personal · Python (stdlib only) · 2025 — present</p>
  <p>
    A single command-line tool that orchestrates the four services my
    team actually lives in — Jira, Confluence, Bitbucket and Webex —
    behind a coherent verb-driven interface. Designed to be driven by
    Claude Code as a first-class user, not bolted on. The repository
    ships with a fully populated <code>CLAUDE.md</code>, explicit
    conventions, and prompt-shaped documentation, so the model can
    propose meaningful actions on day one.
  </p>
  <p>
    What started as a wrapper now powers my weekly delivery rituals:
    drift radars across snapshots, sprint-level forecasts, PR review
    drafts, hygiene audits and quarterly status reports. The same
    discipline applies upward: every report I send to direction is
    drafted, then tightened, by the same pipeline.
  </p>
